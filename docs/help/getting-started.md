# Getting started

Run `kawi` to start with an empty workspace or `kawi path/to/file` to open a file.

Kawi restores the previous workspace when started without a file argument.

## First commands

- `:help` opens this help.
- `:w` writes the current buffer.
- `:q` closes the current window.
- `:q!` discards changes and closes the current window.
- `:wq` writes and closes.
- `:e <path>` edits a file.
- `:set <option>` changes an editor option.

## Modes

The default keymap is Vim-style. Use `i` to insert, Esc to return to normal mode, and `:` to enter a command.
