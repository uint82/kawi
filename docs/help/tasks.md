# Tasks

Tasks are defined in `~/.config/kawi/tasks.toml` and run in the active workspace.

## Commands

- `:task run <name>` run a task
- `:task list` list tasks
- `:task rerun` rerun the last task
- `:task cancel` cancel a running task
- `:task output` show task output
- `:task close` close the task panel

## Keys

- `<leader> t l` list tasks
- `<leader> t r` rerun the last task
- `<leader> t c` cancel
- `<leader> t o` task output
- `<leader> t q` open quickfix
- `<leader> t t` toggle the terminal
