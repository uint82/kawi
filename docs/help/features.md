# Features

- Vim and Helix keymaps.
- Multiple windows and splits.
- Language server support for completion, hover, diagnostics, symbols, rename, formatting, and code actions.
- Fuzzy file, buffer, grep, replace, and symbol pickers with previews.
- Project-wide diagnostics and quickfix navigation.
- Task runner with reusable project tasks.
- Integrated terminal panels.
- Git status, staging, commits, branches, and diffs.
- Autosave, sessions, recovery, macros, undo history, and persistent undo.
- Manual and indentation folding with a fold column.
- Key sequence guidance for leader menus and pending Vim sequences.
- Configurable themes, overlays, and diagnostic presentation.

Use `:help <topic>` to open the guide for a feature.
