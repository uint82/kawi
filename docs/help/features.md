# Features

- Vim and Helix keymaps.
- External file change detection with rename recovery for open buffers.
- Crash-safe explorer renames and deletes with staged rollback and cleanup.
- Multiple windows and splits.
- Opt-in project explorer with file management, Git markers, and diagnostics.
- Editable directory buffers with diff-on-write renames, copies, creates, and trash deletes.
- Language server support for completion, hover, diagnostics, symbols, rename, formatting, code actions, and lifecycle control.
- Built-in Debug Adapter Protocol client with launch, attach, breakpoints, stepping, call stacks, and variables.
- External formatter commands with stdin or file input, format-on-save, and health checks.
- Fuzzy file, buffer, grep, replace, and symbol pickers with previews.
- Project-wide diagnostics and quickfix navigation.
- Task runner with reusable project tasks.
- Integrated terminal panels.
- Git status, staging, commits, branches, and diffs.
- Autosave, sessions, recovery, macros, undo history, and persistent undo.
- Manual and indentation folding with a fold column.
- Key sequence guidance for leader menus and pending Vim sequences.
- Configurable themes, overlays, and diagnostic presentation.
- Process plugins with static command and keybinding contributions, activation events, and bounded event subscriptions, with a deny-by-default capability model.

Use `:help <topic>` to open the guide for a feature.
