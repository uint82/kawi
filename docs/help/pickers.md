# Pickers

Pickers provide fuzzy search, keyboard navigation, and previews where supported.

## Open a picker

- `<leader> f p` project files
- `<leader> f k` open buffers
- `<leader> f s` live grep
- `<leader> f w` grep the word under the cursor
- `<leader> f r` search and replace
- `<leader> s s` document symbols
- `<leader> s w` workspace symbols

Commands are also available:

- `:pick files`
- `:pick buffers`
- `:pick grep`
- `:pick replace`
- `:pick symbols`

Type to filter, use the configured up and down keys to move, and press Enter to open the selection.
