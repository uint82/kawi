# Kawi v0.1.0-alpha.1

Kawi is a fast, modal terminal editor with Vim keymaps, language server support, fuzzy pickers, tasks, terminals, and Git.

This is the first public alpha. It runs natively on Linux and macOS, on x86_64 and arm64.

## Highlights

- Modal editing with multiple windows and splits.
- Language servers, external formatters, diagnostics, and project-wide symbols.
- Fuzzy pickers for files, buffers, live grep, replace, and symbols.
- Project explorer, directory buffers, sessions, recovery, persistent undo, and macros.
- Git status, staging, commits, branches, hunks, and merge conflict resolution.
- Project tasks and integrated terminal panels.
- Managed WebAssembly plugins with checksum verification and a pinned lockfile.
- Native macOS clipboard, Trash, and PTY support.

| Linux x86_64 | `kawi-v0.1.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz` |
| Linux arm64 | `kawi-v0.1.0-alpha.1-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `kawi-v0.1.0-alpha.1-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `kawi-v0.1.0-alpha.1-x86_64-apple-darwin.tar.gz` |

Download the matching archive and `SHA256SUMS` from the release assets, then verify the archive before extracting:

```sh
sha256sum --ignore-missing -c SHA256SUMS
```

On macOS use `shasum -a 256 --ignore-missing -c SHA256SUMS`.

Extract the archive and run the binary:

```sh
tar -xzf kawi-v0.1.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz
./kawi-v0.1.0-alpha.1-x86_64-unknown-linux-gnu/kawi --version
```

## Install with Cargo

```sh
cargo install --git https://github.com/uint82/kawi --tag v0.1.0-alpha.1 --locked kawi
```

## Known limitations

- macOS release binaries are unsigned. If Gatekeeper blocks the binary, clear the quarantine attribute with `xattr -d com.apple.quarantine kawi`.
- Linux binaries are built on Ubuntu 24.04 and require glibc 2.39 or newer.
- Process plugins run without an OS sandbox on macOS. Install only trusted development plugins.
- Files deleted to `~/.Trash` cannot use Finder's Put Back.
- Windows is not supported.
